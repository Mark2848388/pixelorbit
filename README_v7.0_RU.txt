PIXEL ORBIT INFINITE v7.0

Крупное обновление:

1. ЗАДАНИЯ
   - Ежедневные (4 контракта, сброс каждый день)
   - Недельные (3 контракта)
   - Месячные (2 контракта)
   - Награды: кредиты ✦, детали ◆, опыт
   - Серия дней (streak) сохраняется
   - Кнопка «Задания» на главном экране

2. НОВЫЕ ЗДАНИЯ СТАНЦИИ (12 штук)
   - Щит-генератор, Глубинный рудник, Варп-реле
   - Ядро ИИ, Квантовая кузница, Сеть защиты
   - Термоядерный реактор, Казармы, Обсерватория
   - Алиен-артефакт, Торговый узел, Гнездо роя

3. СИНЕРГИИ ЗДАНИЙ
   - Купол + Щит-генератор → +15% щита
   - Генератор + Реактор → ×1.4 пассивного дохода
   - Ангар + Гнездо → +25% урон помощников
   - Матрица + Сеть → усиленные лучи и турели
   - Лаборатория + Обсерватория → +20% опыта
   - Бур + Рудник → усиленная добыча
   - Ядро ИИ + Квантовая кузница → криты и снижение КД
   Активные синергии отображаются на экране заданий.

4. МУЗЫКА
   - Процедурная ambient-музыка (главный экран)
   - Боевой трек (в бою)
   - Кнопка ♪ в шапке для вкл/выкл
   - Настройка сохраняется

5. ЧАТ С ДРУЗЬЯМИ
   - Кнопка «ЧАТ» у каждого друга
   - Локальная история сообщений
   - Готовность к синхронизации через Supabase (таблица pilot_messages)

6. ДИЗАЙН
   - Карточки заданий, прогресс-бары
   - Чат-модалка в пиксельном стиле
   - Полировка dash-карточек и анимаций

Установка:
1. Экспортируй сохранение (ключ pixelorbit_v4).
2. Распакуй ZIP.
3. Замени файлы сайта содержимым папки PixelOrbit.
4. Полностью закрой PWA и открой снова (кэш pixel-orbit-v7-0).

Дополнительно для чата (опционально):
CREATE TABLE IF NOT EXISTS pilot_messages (
  id bigserial primary key,
  sender_id uuid references auth.users,
  receiver_id uuid references auth.users,
  body text,
  created_at timestamptz default now()
);

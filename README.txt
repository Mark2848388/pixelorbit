PIXEL ORBIT INFINITE v4.4 — FRIENDS & CO-OP UPDATE

ЗАПУСК
Откройте игру через HTTPS (например, GitHub Pages). Для онлайна требуется интернет и доступ к Supabase. В index.html подключён официальный браузерный клиент Supabase JS через CDN.

СОВМЕСТИМОСТЬ И СОХРАНЕНИЯ
Используется прежний localStorage-ключ pixelorbit_v4. Прогресс v4/v4.2/v4.3 сохраняется. Перед обновлением рекомендуется сделать резервный экспорт из Профиль → Копировать сохранение.

ЧТО НОВОГО В v4.4
ДРУЗЬЯ И ПРОФИЛИ
- Отдельные группы входящих запросов, списка друзей и отправленных приглашений.
- Принятие и отклонение входящих запросов.
- Поиск друзей по имени и коду пилота.
- Статус «В сети» определяется через Realtime Presence.
- Для отключённых друзей показывается время последнего входа (last_seen).
- Просмотр профиля друга: код, уровень, рекорд волны, боссы, убийства, очки, время в игре и рейд-жетоны.
- Удаление друга из списка.

НАСТОЯЩИЙ ОБЩИЙ КООПЕРАТИВНЫЙ БОСС
- Один глобальный босс НЕБУЛОН с единым запасом здоровья в PostgreSQL.
- Все игроки атакуют одну серверную цель; HP обновляется через Supabase Realtime Postgres Changes.
- Урон рассчитывается на сервере на основе уровня пилота, а не принимается из клиентского сообщения.
- Серверный кулдаун атаки защищает от простого спама.
- Фазы босса: после победы через 30 секунд начинается следующая фаза с увеличенным запасом HP.
- Таблица вклада пяти лучших пилотов текущей фазы.
- За победу каждый пилот, нанёсший урон в фазе, получает 1 рейд-жетон.
- Профиль пилота хранит баланс рейд-жетонов.

ДОПОЛНИТЕЛЬНО
- Панель рейда показывает активных участников, фазу, общий нанесённый урон и личные жетоны.
- Рейд-состояние и вклад игроков хранятся на сервере, переживают перезагрузку браузера.
- Сохранена совместимость с прежним локальным прогрессом и онлайн-функциями v4.3.

SUPABASE

- Новые таблицы: coop_raid_state, coop_raid_contributions.

- Функции рейда проверяют auth.uid(), имеют пустой search_path; EXECUTE отозван у PUBLIC и anon и выдан authenticated.

ПЕРВЫЙ ЗАПУСК / AUTH
Гостевой вход требует включить Anonymous sign-ins в Supabase Dashboard → Authentication → Sign In / Providers → Anonymous. Если не включать его, используйте регистрацию по email и паролю. При включённом подтверждении email подтвердите адрес по письму, затем войдите.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Это бета-реализация глобального рейда: состояние HP, урон, кулдаун и награда авторитетны на сервере, но полноценная симуляция поведения босса (анимации атак, уклонение, роли танка/поддержки, матчмейкинг и отдельные комнаты) пока не реализована.
- Уровень пилота для формулы урона берётся из серверного профиля; этот профиль пока обновляется игровым клиентом, поэтому это не полноценный античит для рейтингового PvP.
- Для корректного статуса «В сети» вкладка игры должна оставаться открытой. После отключения Presence удаляет игрока, а last_seen остаётся в профиле.
- Глобальные рекорды продолжают отправляться через Edge Function pixel-orbit-submit-score.
- Для работы сайта нужен HTTPS и доступ к CDN Supabase JS.

БЕЗОПАСНОСТЬ
В клиенте присутствует только publishable key (публичный ключ проекта). Никогда не добавляйте service_role / secret key в index.html, game.js, hub.js или online.js.


PWA / PWABUILDER
- Добавлены manifest.webmanifest, service-worker.js, pwa.js и иконки 192/512 px, включая maskable.
- Для установки PWA сайт должен быть опубликован по HTTPS (GitHub Pages подходит).
- Опубликуйте содержимое этой папки в корень сайта или в корень GitHub Pages /docs.
- Затем откройте опубликованный HTTPS-адрес в PWABuilder и запустите проверку Manifest/Service Worker.
- PWABuilder обычно анализирует опубликованный URL; ZIP нужен для развёртывания файлов сайта.
- Офлайн-кэш сохраняет оболочку игры и основные файлы. Авторизация, друзья, статусы и рейд требуют интернета.
- После обновления файлов сервис-воркер автоматически заменит старую версию кэша.

PIXEL ORBIT INFINITE v4.3 — ONLINE UPDATE

ЗАПУСК
Откройте игру через HTTPS (например, GitHub Pages). Для онлайна требуется интернет и доступ к Supabase. В index.html подключён официальный браузерный клиент Supabase JS через CDN.

СОВМЕСТИМОСТЬ И СОХРАНЕНИЯ
Используется прежний localStorage-ключ pixelorbit_v4. Прогресс v4/v4.2 сохраняется. Перед первым обновлением всё равно рекомендуется сделать резервный экспорт из Профиль → Копировать сохранение.

ЧТО НОВОГО В v4.3
- Подключён проект Supabase PixelOrbitServer (регион eu-west-1).
- Добавлена регистрация/вход по email и паролю, а также гостевой вход через Anonymous Auth.
- Добавлены серверные профили пилотов с уникальным кодом PO-XXXXXX.
- Добавлены облачное сохранение и загрузка сохранения.
- Добавлен глобальный рейтинг (топ-20), обновляемый из общей базы.
- Добавлены запросы в друзья по коду пилота, принятие запросов и список друзей.
- Добавлен Realtime lobby: список присутствующих пилотов.
- Добавлен кооперативный рейд с общим тренировочным боссом: участники видят синхронизированный запас HP и наносят совместный урон.
- Добавлена Edge Function pixel-orbit-submit-score с обязательной JWT-проверкой. Она публикует профиль и рекорд; прямые клиентские записи в leaderboard запрещены.
- Все пользовательские таблицы защищены RLS. Секретный service_role ключ не включён в браузерную сборку.

ПЕРВЫЙ ЗАПУСК / AUTH
Гостевой вход требует включить Anonymous sign-ins в Supabase Dashboard → Authentication → Sign In / Providers → Anonymous. Если не включать его, используйте регистрацию по email и паролю. При включённом подтверждении email подтвердите адрес по письму, затем войдите.

ОНЛАЙН-СОСТАВЛЯЮЩИЕ
- pilot_profiles — публичные профили пилотов.
- cloud_saves — личные облачные сохранения (доступны только владельцу через RLS).
- leaderboard — рейтинг (чтение авторизованным игрокам; запись через Edge Function).
- friend_requests — запросы дружбы с ограничением на изменение участников запроса.
- Realtime Presence/Broadcast — онлайн-статус и совместный рейд.

ВАЖНЫЕ ОГРАНИЧЕНИЯ
- Кооперативный рейд v4.3 — первый синхронизированный прототип: общий тренировочный босс живёт в Realtime-канале, а не является полноценной серверной симуляцией боя. Урон в рейде передаётся клиентскими событиями; для соревновательного/защищённого PvE потребуется авторитетная серверная логика.
- Глобальные рекорды принимаются только через Edge Function и монотонно обновляются, но игровые показатели поступают от клиента. Это не полноценная защита от читов: для честных турниров нужна серверная проверка событий/сессий.
- Друзья и рейтинг видны после входа в аккаунт. Гостевой аккаунт привязан к браузерной сессии; для надёжного восстановления прогресса лучше использовать email-аккаунт.
- Вкладка должна быть открыта, чтобы игрок отображался онлайн. Realtime Presence автоматически убирает отключившихся.
- Облачное сохранение/загрузка запускаются кнопками в профиле; загрузка заменяет локальный прогресс после подтверждения.
- Для работы сайта нужен HTTPS и доступ к CDN Supabase JS.

БЕЗОПАСНОСТЬ
В клиенте присутствует только publishable key (публичный ключ проекта). Никогда не добавляйте service_role / secret key в index.html, game.js, hub.js или online.js.
